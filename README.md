
# BadgeForge AI

**AI-Powered ID Card Generator for Events and Organizations**

BadgeForge AI is a web-based application designed to simplify the creation of professional ID cards for conferences, college events, workshops, and organizations. It helps users generate customized badge designs from event and participant details.

## 🚀 Live Demo

[**Try BadgeForge AI**](https://badge-forge-ai-five.vercel.app/)

## ✨ Features

- **AI-Assisted Generation:** Create ID card designs from natural-language descriptions.
- **Customizable Designs:** Adapt badges to different events and organizations.
- **Professional Layouts:** Generate structured, visually appealing ID cards.
- **Event-Based Personalization:** Customize event names, participant details, and design elements.
- **Web-Based Interface:** Access the application through a browser.
- **Deployment:** Hosted on Vercel.

## 🎯 Problem Statement

Creating professional ID cards for events can be repetitive and time-consuming. Traditional design workflows often require manual formatting and design expertise.

BadgeForge AI aims to simplify this process by making badge creation more accessible, customizable, and efficient.

## 💡 Our Solution

BadgeForge AI provides a user-friendly interface for creating event badges using user-provided details and design instructions. It aims to reduce manual design effort and help event organizers create consistent ID cards.
